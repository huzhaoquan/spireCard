# 主菜单「杀戮尖塔式」视觉改造计划

## 目标

把当前主菜单改造成更接近《杀戮尖塔》原版菜单的阅读层级和氛围：大幅背景、中央偏上的醒目标题、纵向菜单列表、左上存档信息、右上小型功能入口。改造重点是“构图、色彩、层级、按钮手感”，不直接复制原版 Logo、角色、背景、图标或商标资产。

## 参考特征

- 背景是完整的幻想远景插画，画面右侧有高耸地标，左中区域留给 Logo 和菜单。
- Logo 占据首屏视觉中心，字体大、黄/青高对比、带厚重暗色描边。
- 菜单项是纯文字纵向排列，按钮框弱化，悬停时用亮度/描边/轻微位移动效表达反馈。
- 左上角是当前存档信息，右上角是补丁/说明类小入口，整体 UI 很少使用大面积硬框。
- 前景 UI 与背景之间有轻微暗化蒙层，保证文字可读但不压死背景。

## 现状

- 入口场景：`res://scenes/menu/MainMenu.tscn`
- 主逻辑：`scripts/menu/MainMenu.gd`
- 当前主菜单由脚本动态生成：背景、标题图、右侧大按钮框。
- 当前按钮框偏重，布局更像常规 RPG 菜单，不像原版中央文字列表。

## 改造原则

- 保留项目原创名称，不使用 `Slay the Spire` 原版 Logo。
- 可以借鉴“手绘幻想远景 + 大标题 + 纵向文字菜单”的视觉语言。
- 生成素材时提示词必须包含 `#杀戮尖塔 风格`，同时加入“原创”“不要复制原版 Logo/文字/角色/具体图标”等约束。
- 优先生成位图背景和标题素材；按钮、文字、阴影、蒙层尽量用 Godot 原生 UI 实现，避免过重贴图。
- 所有新增运行时资源放入 `art/backgrounds/menu/` 或 `art/ui/`，保留对应 `.import`。

## 资源计划

使用 `$generate2dsprite` 生成以下资源。

### 1. 主菜单背景

- 输出路径：`art/backgrounds/menu/main_menu_spire_style_bg.png`
- 类型：`prop` / `single` / `clean_hd` / `project-native`
- 尺寸目标：宽屏 16:9，运行时铺满 1920x1080。
- 视觉：手绘幻想城市/尖塔远景，右侧或右中有高塔，天空有橙色日光和冷色云层，左中区域保留暗色留白给标题。
- 提示词草案：

```text
原创 2D 游戏主菜单宽屏背景，#杀戮尖塔 风格，手绘幻想远景，右侧高耸尖塔城市剪影，橙色夕阳云层与冷蓝夜色混合，底部有远处水面和小船剪影，左中区域留出干净暗色空间用于标题和纵向菜单，高对比但不刺眼，层次清晰，1920x1080 composition, no text, no logo, no characters, do not copy Slay the Spire original assets
```

### 2. 原创标题图

- 输出路径：`art/ui/main_menu_spire_title.png`
- 类型：`prop` / `single` / `clean_hd`
- 背景：透明或纯 `#FF00FF` 后处理透明。
- 内容：原创中文标题，建议暂用「尖塔卡牌」或「Spire Card」二选一。
- 视觉：黄色主字、青蓝高塔形副元素、厚暗描边、轻微不规则手绘边缘。
- 提示词草案：

```text
原创游戏标题图，文字为“尖塔卡牌”，#杀戮尖塔 风格，黄金额主标题字，青蓝色高塔形装饰字母元素，厚重黑色描边，手绘奇幻卡牌游戏 logo 气质，透明背景或纯 #FF00FF 背景，居中构图，no English Slay the Spire text, no copied logo, no trademark symbols
```

> 不确定项：标题最终用「尖塔卡牌」还是英文/中英混排，需要确认。

### 3. 存档角标小图标

- 输出路径：`art/ui/menu_save_badge.png`
- 类型：`prop` / `single` / `clean_hd`
- 用途：左上存档槽图标，可选。若生成不理想，用原生 ColorRect + 小图标兜底。
- 提示词草案：

```text
原创小型存档角标图标，#杀戮尖塔 风格，手绘羊皮纸与红色印章，适合游戏主菜单左上角，透明背景或纯 #FF00FF 背景，清晰小尺寸可读，无文字，不复制原版图标
```

### 4. 右上说明卷轴图标

- 输出路径：`art/ui/menu_note_icon.png`
- 类型：`prop` / `single` / `clean_hd`
- 用途：右上角版本/说明入口。非必须。
- 提示词草案：

```text
原创小型卷轴说明图标，#杀戮尖塔 风格，手绘羊皮纸卷轴，深色描边，暖色高光，透明背景或纯 #FF00FF 背景，适合右上角 UI 按钮，无文字，不复制原版图标
```

## UI 布局计划

### 背景层

- 使用新背景 `main_menu_spire_style_bg.png` 全屏铺满。
- 叠加轻微暗色蒙层：整体 `0.12-0.22 alpha`。
- 左中菜单区域可加垂直渐变暗化，但不使用明显卡片框。

### 左上存档信息

- 位置：`(24, 22)` 附近。
- 内容：
  - 小图标/色块
  - `存档1`
  - `点击编辑`
- 字体：中文清晰字体，字号约 20 / 16。
- 颜色：标题金色，副标题青蓝。

### 标题

- 位置：屏幕中上偏左，约 `x=420-1040, y=210-560`。
- 如果标题生成效果稳定：使用 `TextureRect`。
- 若标题生成中文字质量不稳定：改成 Godot Label 组合，标题素材只保留装饰背景/塔形元素。

### 菜单项

- 菜单居中偏下，竖排纯文字：
  - 继续游戏
  - 开始游戏
  - 设置
  - 退出游戏
- 暂不做“多人模式 / 时间线 / 百科大全”等未实现入口，避免误导。
- 文字样式：
  - 默认：浅灰白，暗描边
  - Hover：金色或亮白，轻微放大 `1.04`，向右偏移 `8px`
  - Pressed：短暂压暗
- 不再使用大装饰按钮框。

### 右上入口

- 小型卷轴/设置按钮，尺寸控制在 `52-64px`。
- 版本号如需要可放右上淡灰小字，默认不抢主视觉。

## 实现步骤

1. 生成并处理背景图：`art/backgrounds/menu/main_menu_spire_style_bg.png`。
2. 生成并处理标题图：`art/ui/main_menu_spire_title.png`。
3. 视生成质量决定是否生成存档和说明小图标。
4. 修改 `scripts/menu/MainMenu.gd`：
   - 替换背景资源路径。
   - 重做 `_add_title_block()`，标题居中偏上。
   - 重做 `_add_menu_buttons()`，改为纯文字纵向列表。
   - 删除/停用 `menu_button_ornament` 的主菜单按钮框。
   - 新增左上存档信息和右上小入口。
5. 保持现有按钮逻辑：
   - 开始游戏：`start_new_run` 后进入地图。
   - 继续游戏/设置：先保留打印或禁用态，后续再接功能。
   - 退出游戏：保持退出。

## 验收标准

- 进入主菜单后第一眼能看到背景、标题、菜单三层信息，视觉中心明确。
- 菜单项不再被重型按钮框包住，接近原版纯文字列表节奏。
- 左上存档信息和右上小入口存在但不抢主视觉。
- 1920x1080 下文字不重叠、不贴边、不被背景吃掉。
- 没有直接复制原版 Logo、原版标题文字、原版角色或原版图标。
- Godot 运行时无缺资源报错。

## 风险与兜底

- AI 生成中文标题可能字形不稳定：兜底为 Godot Label + 生成装饰元素。
- 背景如果过亮或过花：用运行时暗化蒙层和左侧渐变控制可读性。
- 图标如果复杂度过高：不用图标，改用原生文本/小色块。

## 需要确认

- 游戏标题最终使用「尖塔卡牌」「Spire Card」还是其他名称？
- 主菜单是否保留“继续游戏”，还是第一版只显示“开始游戏 / 设置 / 退出游戏”？
- 是否需要显示版本号或构建日期？

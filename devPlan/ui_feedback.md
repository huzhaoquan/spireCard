  # 战斗 UI 信息层级与动作反馈优化计划                                                                                                                        
                                                                                                                                                              
  ## Summary                                                                                                                                                  
                                                                                                                                                              
  目标是把当前战斗界面从“功能组件摆放正确”提升到“战斗信息一眼可读、操作反馈明确、整体更像完整卡牌战斗舞台”。第一轮优先优化底部手牌 HUD、结束回合按钮、敌人意  
  图、角色站位、血条格挡和出牌反馈。                                                                                                                          
                                                                                                                                                              
  ## Key Changes                                                                                                                                              
                                                                                                                                                              
  - 底部手牌 HUD：                                                                                                                                            
      - 使用 generate2dsprite 生成暗色金属/羊皮纸风格弧形手牌托盘。                                                                                           
      - 手牌整体上移并略微放大，保留扇形布局。                                                                                                                
      - 能量球移入手牌 HUD 左侧。                                                                                                                             
      - 增加抽牌堆和弃牌堆图标，只显示数量，不做点击详情。                                                                                                    
      - 拖拽攻击牌时，敌人区域出现红色目标高亮。                                                                                                              
  - 结束回合按钮：                                                                                                                                            
      - 使用 generate2dsprite 生成右下角金属/石板按钮框。                                                                                                     
      - 替换默认 Button 外观，支持 normal / hover / pressed / disabled 四态。                                                                                 
      - 保持现有结束回合逻辑不变。                                                                                                                            
  - 敌人意图 UI：                                                                                                                                             
      - 使用 generate2dsprite 生成红色攻击意图图标。                                                                                                          
      - 将当前“意图：攻击 6”文字改为敌人头顶图标 + 数字。                                                                                                     
      - v1 只支持攻击意图，接口预留后续防御、强化、debuff。                                                                                                   
  - 角色、敌人与血条：                                                                                                                                        
      - 调整玩家和敌人站位，增强左右对峙感。                                                                                                                  
      - 略微放大角色和敌人，但保持脚底落在地面透视上。                                                                                                        
      - 血条加粗、加描边，数字居中。                                                                                                                          
      - 格挡现在颜色过于单薄，需要优化颜色显示，使其立体化。                                                                                                                
  - 出牌反馈：                                                                                                                                                
      - 攻击牌打出后飞向敌人，播放斩击，并显示伤害数字。                                                                                                      
      - 防御牌打出后玩家身上显示蓝色盾牌闪光，格挡数字跳动。                                                                                                  
      - 角色受击时增加轻微震动。                                                                                                                              
      - 无效拖拽保留回弹，并增加短暂红色提示。                                                                                                                
  - 顶部栏降噪：                                                                                                                                              
      - 保留玩家名、HP、金币、楼层、地图、牌库、设置。                                                                                                        
      - 改成更轻的半透明战斗 HUD，减少工具栏感。                                                                                                              
      - 图标分组更紧凑，降低黑色矩形面积。

      - 新增敌人意图图标 UI。                                                                                                                                 
      - 新增伤害数字、格挡反馈、受击反馈触发。                                                                                                                
  - 修改 BattleActorView：                                                                                                                                    
      - 精修血条和格挡 UI。                                                                                                                                   
      - 格挡图标颜色优化

  - 修改 BattleTopDock：

  ## Test Plan                                                                                                                                                
                                                                                                                                                              
  - 进入战斗后底部 HUD、手牌、能量、抽弃牌堆、结束回合按钮显示正常。                                                                                          
  - 攻击牌拖到敌人区域时目标高亮，释放后扣能量、造成伤害、显示伤害数字。                                                                                      
  - 防御牌打出后玩家获得格挡，蓝色菱形显示在血条左侧。                                                                                                        
  - 结束回合仍能进入敌人回合，再回到玩家回合。                                                                                                                
  - 敌人意图图标和数字在敌人头顶清晰可读。                                                                                                                    
  - 胜利/失败流程不受影响。                                                                                                                                   
                                                                                                                                                              
  ## Assumptions                                                                                                                                              
                                                                                                                                                              
  - 第一轮只优化 UI 和反馈，不重做角色/敌人 sprite。                                                                                                          
  - 抽牌堆和弃牌堆暂时只显示数量。                                                                                                                            
  - 敌人意图 v1 只实现攻击。                                                                                                                                  
  - 不改卡牌数据结构、不改战斗状态机、不改地图/商店/休息逻辑。

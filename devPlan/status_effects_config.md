# 战斗状态配置

## 设计目标

状态效果统一使用 `status_effects` 字典保存，键为状态 id，值为层数或持续回合数。力量仍保留为一等属性 `strength`，但显示和结算规则纳入本配置。

当前状态定义已同步到 `BattleScene.gd` 的 `STATUS_DEFINITIONS`。

## 状态表

| id | 名称 | 简写 | 层数含义 | 衰减时机 | 结算规则 |
|---|---|---|---|---|---|
| `strength` | 力量 | 力 | 数值属性 | 不衰减 | 攻击伤害基础值 + 力量。玩家和敌人都可拥有。 |
| `dexterity` | 敏捷 | 敏 | 数值属性 | 不衰减 | 获得格挡时，格挡值 + 敏捷。 |
| `vulnerable` | 易伤 | 易 | 持续回合 | 目标自身回合结束时 -1 | 受到攻击伤害 x1.5，向下取整。 |
| `weak` | 虚弱 | 弱 | 持续回合 | 目标自身回合结束时 -1 | 造成攻击伤害 x0.75，向下取整。 |
| `frail` | 脆弱 | 脆 | 持续回合 | 目标自身回合结束时 -1 | 获得格挡 x0.75，向下取整。 |
| `execution_mark` | 处刑印记 | 印记 | 特殊标记 | 不自然衰减 | 鸦冠处刑者的连斩和处决追加伤害；处决后移除。 |

## 当前接入来源

| 来源 | 状态 |
|---|---|
| 重击 | 对敌人施加 2 层易伤。 |
| 观察弱点 | 若敌人意图为攻击，玩家获得 3 力量。 |
| 恶魔形态 | 玩家每回合开始获得 2 力量。 |
| 鸦冠处刑者：破绽凝视 | 对玩家施加处刑印记。 |
| 鸦冠处刑者：架势调整 | 敌人获得 2 力量。 |
| 裂核史莱姆：酸液撞击 | 对玩家施加 1 层虚弱。 |
| 裂核史莱姆：裂核膨胀 | 敌人获得 3 力量。 |
| 铸魂暴君：战意升温 | 敌人获得 3 力量。 |
| 铸魂暴君：王座压迫 | 对玩家施加 2 层虚弱，并使玩家下回合少抽 1 张牌。 |
| 铸魂暴君：黑铁壁垒 | 对玩家施加 2 层脆弱。 |

## 战斗结算顺序

1. 攻击基础伤害确定。
2. 攻击方力量加入伤害。
3. 特殊动作加成结算，例如处刑印记、腐蚀格挡。
4. 防御方易伤和攻击方虚弱修正伤害。
5. 格挡抵消伤害，剩余伤害扣 HP。
6. 获得格挡时先加敏捷，再受脆弱修正。
7. 玩家状态在玩家回合结束时衰减；敌人状态在敌人回合结束时衰减。

## 后续扩展格式

卡牌对敌人施加状态：

```gdscript
{"apply_enemy_status": {"vulnerable": 2}}
```

敌人行动对玩家施加状态：

```gdscript
{"name": "酸液撞击", "damage": 10, "apply_player_status": {"weak": 1}}
```

新增状态时需要同步两处：

- `BattleScene.gd` 的 `STATUS_DEFINITIONS`
- 本文档的状态表和接入来源

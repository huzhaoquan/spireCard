# 战斗后卡牌掉落奖励规则计划

## 目标

设计一套接近《杀戮尖塔》节奏、但适配当前项目规模的战斗后卡牌奖励规则。

本计划只定义规则和数据结构，不在本阶段改 UI 或战斗流程。后续应在战斗胜利后进入奖励界面，让玩家从若干张卡牌中选择 1 张加入牌组，也可以跳过。

## 当前实施状态

- 已新增 `res://scenes/reward/CardRewardScene.tscn` 和 `scripts/reward/CardRewardScene.gd`。
- 战斗胜利后点击继续会进入卡牌奖励界面。
- 奖励界面按 `battle_normal`、`battle_elite`、`battle_boss` 生成 3 张候选卡。
- 玩家点击 1 张卡会调用 `GameManager.add_card(card_data)`，随后完成当前地图节点并返回地图。
- 玩家点击 `跳过奖励` 会直接完成当前地图节点并返回地图。
- `MapScene` 已在进入节点时记录 `current_node_type`，奖励界面用它区分普通、精英和 Boss。
- `GameManager` 已记录普通怪奖励保底计数 `card_reward_pity_counter`。
- 尚未实现奖励界面的高级视觉背景、奖励音效和卡牌升级掉落。

## 基础原则

- 每场战斗胜利后展示卡牌奖励候选，不直接自动加入牌组。
- 每次奖励默认展示 3 张卡牌。
- 玩家可以选择 1 张加入 `GameManager.deck_cards`，也可以跳过。
- 初始牌 `打击`、`防御`、`重击` 不进入常规奖励池，避免污染成长选择。
- 奖励卡池优先围绕已规划的两套铁甲战士流派：
  - 力量爆发流：`恶魔形态`、`观察弱点`、`突破极限`、`双发`
  - 全身撞击流：`全身撞击`、`壁垒`、`无惧疼痛`、`盛怒`
- 后续新增卡牌时，只需要扩展卡池表和权重，不重写奖励流程。

## 卡牌稀有度

当前先沿用三档稀有度：

| 稀有度 | 用途 | 当前卡牌 |
| --- | --- | --- |
| Common | 基础构筑组件，出现频率最高 | `全身撞击` |
| Uncommon | 流派过渡与核心辅助 | `观察弱点`、`无惧疼痛`、`盛怒` |
| Rare | 构筑核心或爆发组件 | `恶魔形态`、`突破极限`、`双发`、`壁垒` |

当前 Common 数量偏少，后续需要补充更多普通攻击、防御、过牌和消耗组件，否则普通战斗奖励会过早重复。

## 普通怪奖励

普通怪用于提供稳定成长和流派起点。

| 项目 | 规则 |
| --- | --- |
| 候选数量 | 3 张 |
| 可跳过 | 是 |
| 稀有度权重 | Common 65%，Uncommon 30%，Rare 5% |
| 重复控制 | 同一次奖励中不出现重复 `id` |
| 流派倾向 | 若牌组已有某流派卡牌，同流派卡权重 +20% |
| 保底规则 | 连续 3 次普通怪奖励没有出现 Uncommon 或 Rare 时，下一次至少 1 张 Uncommon |

普通怪候选示例：

- `全身撞击`
- `观察弱点`
- `盛怒`

## 精英怪奖励

精英怪用于明显提高构筑强度，应该更容易给到核心牌。

| 项目 | 规则 |
| --- | --- |
| 候选数量 | 3 张 |
| 可跳过 | 是 |
| 稀有度权重 | Common 35%，Uncommon 45%，Rare 20% |
| 重复控制 | 同一次奖励中不出现重复 `id` |
| 流派倾向 | 若牌组已有某流派卡牌，同流派卡权重 +30% |
| 保底规则 | 至少 1 张 Uncommon 或以上 |
| 特殊规则 | 精英战后不掉初始牌，不掉纯数值弱卡 |

精英怪候选示例：

- `观察弱点`
- `无惧疼痛`
- `突破极限`

## Boss 奖励

Boss 奖励应提供构筑定型机会，优先给强核心和跨流派关键牌。

| 项目 | 规则 |
| --- | --- |
| 候选数量 | 3 张 |
| 可跳过 | 是 |
| 稀有度权重 | Uncommon 30%，Rare 70% |
| 重复控制 | 同一次奖励中不出现重复 `id` |
| 保底规则 | 至少 2 张 Rare |
| 特殊规则 | Boss 奖励池优先抽取 `核心牌` 标记卡 |

Boss 核心牌池：

| 流派 | 核心牌 |
| --- | --- |
| 力量爆发流 | `恶魔形态`、`突破极限`、`双发` |
| 全身撞击流 | `壁垒`、`无惧疼痛`、`全身撞击` |

Boss 候选示例：

- `恶魔形态`
- `壁垒`
- `双发`

## 流派权重规则

为了让构筑更容易成型，奖励生成时统计玩家当前牌组中已有的流派标签：

| 标签 | 关联卡牌 |
| --- | --- |
| `strength` | `恶魔形态`、`观察弱点`、`突破极限`、`双发` |
| `block_damage` | `全身撞击`、`壁垒`、`无惧疼痛`、`盛怒` |
| `power` | `恶魔形态`、`壁垒`、`无惧疼痛` |
| `exhaust` | `无惧疼痛`、`突破极限` |

权重应用：

- 如果牌组已有某标签卡牌，该标签下的候选卡增加权重。
- 如果牌组完全没有流派倾向，按基础稀有度权重抽取。
- 如果某张卡已在牌组中超过 2 张，降低其再次出现权重 50%。
- `恶魔形态`、`壁垒` 这类高费用能力牌最多允许高权重推荐 1 张，避免手牌过重。

## 奖励生成流程

1. 根据战斗类型读取基础奖励配置：
   - `normal`
   - `elite`
   - `boss`
2. 统计当前牌组里的流派标签和重复数量。
3. 按战斗类型决定本次奖励的稀有度分布。
4. 从对应稀有度卡池中按权重抽取候选卡。
5. 应用去重：
   - 同一次奖励不重复。
   - 若抽到已超过推荐数量的卡，降低权重或重抽。
6. 应用保底：
   - 精英至少 1 张 Uncommon 或 Rare。
   - Boss 至少 2 张 Rare。
7. 生成 3 张候选卡，进入奖励界面。
8. 玩家选择 1 张后调用 `GameManager.add_card(card_data)`。
9. 玩家跳过则直接返回地图或进入下一奖励环节。

## UI 需求

奖励界面应包含：

- 3 张卡牌候选，使用现有 `CardView` 展示。
- 每张卡点击后加入牌组。
- `跳过` 按钮。
- 奖励标题：
  - 普通怪：`战斗奖励`
  - 精英怪：`精英奖励`
  - Boss：`Boss 奖励`
- 如果奖励来自 Boss，可在标题或背景上强化视觉表现。

## 验证项

- 普通怪奖励显示 3 张卡，Rare 出现率明显低。
- 精英怪奖励至少出现 1 张 Uncommon 或 Rare。
- Boss 奖励至少出现 2 张 Rare。
- 同一次奖励不会出现重复卡牌。
- 选择卡牌后 `GameManager.deck_cards` 增加对应 `id`。
- 跳过奖励不改变牌组。
- 购买或奖励获得的卡牌能在下一场战斗进入抽牌堆。

## 后续扩展

- 增加更多 Common 卡，改善普通怪奖励的重复问题。
- 加入升级牌掉落概率，例如普通怪 5%、精英 15%、Boss 30%。
- Boss 后续应额外掉落遗物或能量遗物，本计划只处理卡牌奖励。
- 奖励界面完成后，可把商店当前固定 8 张卡改为随机商品池。

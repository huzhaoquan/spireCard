# 主菜单 / 商店 / 休息点 UI 风格化改造

## 目标

把当前纯色占位界面改造成暗黑手绘爬塔卡牌风格，提升主菜单、商店和休息点的可读性与氛围。风格参考《杀戮尖塔》的暗黑奇幻、羊皮纸、木质面板和暖色火光，但不复刻原作素材。

## 资产

使用 `generate2dsprite` 流程生成并接入：

- `art/backgrounds/menu/main_menu_bg.png`
- `art/backgrounds/shop/shop_bg.png`
- `art/backgrounds/rest/rest_bg.png`
- `art/ui/menu_shop_rest_ui_raw.png`
- `art/ui/menu_button_ornament.png`
- `art/ui/shop_shelf_panel.png`
- `art/ui/tooltip_panel_frame.png`
- `art/ui/rest_campfire_icon.png`
- `art/ui/upgrade_card_icon.png`
- `art/ui/sold_out_stamp.png`

## 实施内容

- 主菜单：
  - 全屏背景图 + 暗角遮罩。
  - 左侧标题和副标题。
  - 右侧纵向菜单按钮，带装饰图和自定义 hover 样式。
  - 菜单按钮装饰图重新按 Alpha 内容裁切，按钮和装饰使用同一矩形，避免文字与插画错位。
  - 主标题新增 `art/ui/main_menu_title.png`，使用描边金色艺术字图片展示。
  - 三次修正：恢复原始生成的手绘木质按钮框，只做更干净的洋红去背和最大连通域清理。
  - 三次修正：按钮框按原图比例显示为 `430x182`，文字只占木牌中心安全区，不再压扁插画。
  - 三次修正：主标题改为行楷/隶书方向的红金重描边图片，去掉圆润卡通三角装饰。
  - 保留开始游戏、继续游戏、设置、退出游戏原行为。

- 商店：
  - 全屏商店背景图 + 顶部金币栏。
  - 中央货架面板承载 6 个商品。
  - 商品卡片改为自定义面板，包含预览区、类型、名称、价格、购买按钮。
  - 已售出显示透明印章图，金币不足保留抖动反馈。
  - 二次修正：货架装饰重制为 `1492x656` 横向资源，避免方形插画拉伸变形。

- 休息点：
  - 全屏营火背景图。
  - HP 信息牌带生命图标。
  - 休息和升级改为两个大操作卡片，分别展示营火和升级卡牌图标。
  - 保留休息回血、升级占位、返回地图原行为。

- 字体：
  - 标题、按钮、商品名和主要操作文字使用 `SystemFont` 候选列表，优先尝试隶书/姚体/行楷风格中文字体。
  - 普通说明文字使用更稳的中文字体候选，保留可读性。

## 验证项

- 主菜单启动后背景不再是纯黑，按钮 hover 正常，开始游戏进入地图。
- 商店显示金币，购买扣金币，金币不足提示，已售出不可重复购买，返回地图完成节点。
- 休息点显示 HP，休息恢复最大生命值 30%，休息按钮禁用，返回地图完成节点。
- 1920x1080 下文字不重叠，不压住插画主体。

## 约束

- 不改 GameManager 公共接口。
- 不改大地图、战斗、事件和宝箱逻辑。
- 删除卡牌和升级卡牌仍保持占位行为。
